## Defaults wrap existing notices

Defaults and Consortia install modes wrap each library’s **existing** Koha notice text in CirriusImpact YAML (preserving wording) and archive the original as Template Toolkit comments. CI templates mode still installs canned `CODE-CI` samples only.

See **RELEASE_NOTES_v1.3.4.md** for the full description and package.
